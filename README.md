# ECHOSYSTEM Genome Loom

This repository contains a minimal React + TypeScript + Vite scaffold for the Genome Loom application.

Goals:
- Fast, runnable scaffold: npm install && npm run dev
- Canvas-based renderer for a radial genome
- Left/center/right panels and basic UI controls

What I added in the initial commit:
- Vite + React + TypeScript scaffold
- Basic components under src/components
- Renderer utilities under src/renderer
- A small app state hook in src/state/useGenome.ts

Fastest upload path:
1) Locally: git clone, add remote, push (recommended when you have Git locally).
2) Via GitHub web UI: upload the generated files as a zip or drag-and-drop files.
